# RAG Prototype for Scientific Publications Analysis

This repository contains a prototype of a Retrieval-Augmented Generation (RAG) system developed as part of a Bachelor's thesis (VKR).

**Thesis topic:** "RAG Prototype for Scientific Publications Analysis"

## Files

- `grobid_server.ipynb` — launches the GROBID server for scientific document processing.
- `rag_prototype.ipynb` — main notebook containing the project's implementation and workflow.

## Running the Project

The full project is stored on Google Drive and designed to run in **Google Colab**.

Open the notebooks in Colab and follow the execution steps provided within them.
